上传代码
初始化第一次上传
git init 
 git add .
 git commit -m "更新内容"
 git branch -M main     
 git remote add origin https://github.com/21445/ShuaTiBao.git
 git push -u origin main


第二次提交
git add .
git commit -m "第二次提交"
git push

下载代码
git clone https://github.com/21445/ShuaTiBao.git
git pull
